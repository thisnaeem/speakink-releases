# SpeakInk Releases

Windows installers and the auto-update feed for **SpeakInk** — fully local AI dictation for Windows (formerly VoicePaste).

SpeakInk releases live here from v0.6.0 onward. Existing VoicePaste installs receive v0.6.0 through the old voicepaste-releases feed once; after that update the app checks this repo for updates.
